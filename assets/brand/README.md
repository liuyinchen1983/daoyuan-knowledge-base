# 品牌素材说明

## 当前内容

`app_icon.ico` 是仓库自带的**中性占位图标**，用于源码运行和打包示例，不包含任何第三方商标或用户提供的 Logo。

## 替换为自有 Logo

1. 确认你拥有该图片的版权或使用授权。
2. 准备正方形 PNG（建议 1024×1024，透明背景）。
3. 使用项目脚本生成多尺寸 ICO，或自行转换为包含 16/24/32/48/64/128/256 像素的 ICO。
4. 覆盖 `assets/brand/app_icon.ico` 后重新打包。

打包配置通过相对路径引用该文件，不需要修改 `.spec`。

## 不要提交的内容

- 未经授权的他人 Logo、公众号头像、文章配图。
- 含个人信息的截图或带水印的素材。
- 真实用户数据、二维码或联系方式。

`assets/brand/logo.png` 和根目录 `logo图.png` 已被 `.gitignore` 排除，避免把本机私有素材带入仓库。
