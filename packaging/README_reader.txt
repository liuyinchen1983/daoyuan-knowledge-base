道源知识库（普通用户端）
========================

用途：离线阅读已导入的公众号文章，支持全文检索、专题库、道源智问、TXT/Word/PDF 导出。
本目录是完整的 onedir 程序目录，不能只拷贝 exe 而遗漏 _internal 目录。

启动：双击 道源知识库.exe。
数据：默认读取 %USERPROFILE%\DaoYuanData，可在配置文件中修改。
说明：阅读、检索和导出不需要 DeepSeek Key，也不依赖 Python 环境。
      智问联网功能需要用户在软件内配置自己的 DeepSeek Key。

专题库：按「人物 / 组织与势力 / 地点与场景 / 概念与设定 / 物件与技术 /
        剧情与伏笔」目录树显示维护端已收录的条目，可点「打开文章」回到原文
        段落。未收录的候选不会出现在这里。

本程序不包含公众号采集、采集计划任务或维护端管理页面。
